Identifizierte Probleme & Lösungen
Problem 1: Device nicht im Dropdown sichtbar

Device 003015 in DB vorhanden, aber nicht in Streamlit-Dropdown
Ursache: SQL ORDER BY id sortiert alphanumerisch statt numerisch
Lösung: ORDER BY CAST(id AS UNSIGNED)

Problem 2: Bild in DB aber "No images found"

Anthony's System schreibt in bears_images_unified
Japan-System las aus veralteter Tabelle image_metadata
Lösung: Japan-System auf bears_images_unified umgestellt

Problem 3: Image Type Mismatch

Bild als image_type='trail' gespeichert (Filename enthält t)
User klickte "Load Device Images" → suchte image_type='device'
Lösung: Korrektes Laden über "Load Trail Images"

Problem 4: parsed_successfully = 0

OCR erkannte keinen Timestamp im Bild-Overlay
Query filtert WHERE parsed_successfully = 1
Bild wurde herausgefiltert

Problem 5: Timestamp = NULL

Date/Time Filter in Sidebar filtert timestamp IS NOT NULL
NULL-Timestamps ausgeschlossen
Ursache: OCR konnte Timestamp nicht aus Bild extrahieren

Problem 6: Filename-Pattern nicht erkannt

Code extrahierte Timestamp nur aus Format 2: YYYY.MM.DD.HHMM
Format 1: t_YYMMDD nicht implementiert
Lösung: Erweiterte extract_filename_information() Methode
